## Items deliberately left for administrator verification

1. The course tables provide faculty abbreviations/names, but not the API's employee IDs or emails. These must come from the approved faculty master; the demo does not fabricate them.
2. The `L & AB x/y` and `EN 2/12` location strings do not specify a confirmed room inventory, capacities, or equipment. Do not turn them into room records without the institution's room mapping.
3. Weekly contact hours are visible, but session length and whether lab contact hours apply per batch or in aggregate need administrator confirmation before creating solver assignments. In particular, AMT-1 separates `2 + 4 (TUT)` and FS Java appears as both Theory and Lab under code 2343611.
4. TE IT lists MCD501 for two distinct MDM streams (theory and lab). The current application treats a subject code as unique within a semester, so the source streams need an approved distinct identifier or a schema/reference decision before import.
5. The BE IT Friday lunch/lab timing conflicts with the common period header as described above.
6. A few small-print location allocations and faculty-to-batch merged cells should be checked against the original PDF pages before production import.

The seeded semester grids use the common printed header but remain `draft` with `configurationVerified: false`; BE IT's Friday exception is explicitly noted. All seeded batch labels are flagged for review. The demo workbook is a source-transcription and layout example, **not an API import workbook** and not a generated timetable. The solver continues to generate schedules from assignments; no reference schedule is hardcoded into it.
